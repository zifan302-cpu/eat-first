# Eat First 分类角色初始母版 V1

## 状态

- 仅供造型审核，尚未接入产品。
- 使用内置图像生成工具逐类生成，每个分类一次独立调用。
- `raw/` 保留纯色键背景原图。
- `transparent/` 为本地色键去背景后的透明 PNG。
- `category-masters-review.png` 为编号审核总览。

## 固定参考

1. `../fresh-squad-family-style-reference.png`
   - 家族轮廓、脸部尺度、短肢体、低重心、毛毡剪纸质感和克制表情。
2. `../tomato-freshness-state-reference.png`
   - 只参考第一阶段的新鲜状态能量，不复制番茄轮廓、颜色或叶冠。

## 固定生成约束

- 每张图只有一个完整角色，食物或包装本身就是身体。
- 两只靠近的深墨绿色种子形小眼睛，一条短而略偏心的嘴。
- 无鼻子、眉毛、腮红、牙齿、手指、手套、鞋、衣服、徽章、工具或道具。
- 两条低位短手臂、两条短腿、低矮圆脚，接近正面端正站立。
- 二维软边剪纸色块，只有轻微短毛毡纤维，哑光、安静、接近扁平。
- 方形构图、完整全身、四周留白、缩小到 40–72 px 时仍可读。
- 无文字、品牌、标志、水印、场景、地面、投影和反射。

## 后续状态扩展

每个通过审核的初始母版应作为该分类的身份参考图。后续保质期状态只改变姿态、能量和轻微柔化程度，不重新设计轮廓、脸部位置、肢体比例、颜色体系或主要识别点。
