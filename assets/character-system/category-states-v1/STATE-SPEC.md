# Eat First 分类角色状态母版 V1

## 状态层级

分类角色保留初始母版作为 `fresh`。本轮只新增两种日期状态：

- `use_soon`：临近日期，仍可处理。角色只是轻微疲惫，提醒用户优先安排。
- `expired`：已过日期，需要用户判断。角色更低能量，但不表达羞耻、恐惧或食品安全结论。

## 固定不变量

- 保留每个分类原有轮廓、脸部位置、肢体比例、主色、材质和关键识别点。
- 食物或包装本身就是身体；不添加衣服、工具、徽章、文字或状态图标。
- 两只深墨绿色小眼睛、一条短嘴、短手臂和低矮圆脚。
- 二维软边剪纸与轻微毛毡纤维质感；近正面、低重心、完整全身。
- 状态只改变姿态、能量、表情和轻微柔化程度，不重新设计身份。
- 缩小到 40–72 px 时仍须可辨认。

## 状态语言

### use_soon

- 约 8° 的轻微倾斜或下沉，不做夸张动作。
- 手臂略向内、眼睛保持睁开、嘴接近水平并带一点不确定感。
- 主色最多柔化约 8%，不出现变质痕迹。

### expired

- 约 15° 的温和塌低姿态，手臂自然下垂。
- 眼睛略低、嘴轻微向下，表达“需要处理”而非“生病”。
- 主色最多降低约 16% 饱和度；允许轮廓轻微变软，但不得破坏分类识别。

## 禁止表现

- 霉斑、腐烂、瘀伤、破口、渗漏、黏液、苍蝇、臭味线。
- 眼泪、汗滴、恐慌、恶心、痛苦、羞耻或恐怖表达。
- 投影、地面、场景、反射、水印和文字。

## 文件约定

- `raw-sheets/`：图像生成得到的纯色键背景双状态母版；左侧为 `use_soon`，右侧为 `expired`。
- `transparent/`：从双状态母版拆分、去背后的透明 PNG。
- `category-states-review.png`：14 个分类的三态审核总览，顺序为 `fresh / use_soon / expired`。
